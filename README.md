# Thunderbird Add-ons

Thunderbird add-ons, written for a real teaching and research mail workflow.

| Add-on | What it does | Built on | Docs |
|---|---|---|---|
| [`mail-merge-html-preview`](mail-merge-html-preview/) | Mail Merge's **Message** tab shows each merged email rendered, as the recipient will see it, instead of its HTML source. It also flags merge fields that will come out empty. | [Mail Merge 11.6.1](https://addons.thunderbird.net/addon/mail-merge/) by Alexander Bergmann (GPL-3.0). Preview design inspired by [MailMergeP](https://github.com/siefkenj/MailMergeP). | [README](mail-merge-html-preview/README.md) |

Installable `.xpi` packages are attached to the [Releases](https://github.com/ilker-golcuk/thunderbird-addons/releases).
